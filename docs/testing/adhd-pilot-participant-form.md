# ADHD Assist pilot — participant reaction form

**Fill this in yourself** after you read each tutor reply. Your facilitator will paste the chat messages — you do not need to toggle anything.

**Scale for all 1–7 questions:**  
`1` = strongly disagree · `4` = neither · `7` = strongly agree

**Privacy:** Use participant code `P__` only — no full name on this form unless your consent says otherwise.

---

## Session header (facilitator fills once)


| Field             | Value                         |
| ----------------- | ----------------------------- |
| Session ID        | e.g. `PILOT-2026-06-01-01`    |
| Participant code  | P__                           |
| Date              |                               |
| Ethics tier       | A / B / C                     |
| Condition order   | Baseline first / Assist first |
| Model (info only) |                               |


---

## How to use this form

You will try the **same three tasks twice** — once with **Assistive mode Off**, once with **Assistive mode On**. After each task block, rate **the last reply you saw** in that block.


| Block  | What you will do                                                       |
| ------ | ---------------------------------------------------------------------- |
| **T1** | One question about gradient descent                                    |
| **T2** | Three messages about washing dishes (includes a tricky second message) |
| **T3** | A study plan, then “pick up where we left off”                         |
